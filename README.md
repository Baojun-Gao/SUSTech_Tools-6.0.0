# 南科大Tis选课助手  
## 🔧 本维护版修复内容（基于 v5.0.0）

南科大 CAS 系统于 2026 年 9 月更新了认证流程，原版本中的 Cookie 手动提取方式（`route` 和 `JSESSIONID`）已失效。本版本对此进行了重构：

- 改用 `requests.Session` 自动管理会话，不再依赖特定 Cookie 字段；
- 重写 `cas_login` 函数，支持动态提取 `execution`、`lt`、`service` 等隐藏字段；
- 所有网络请求（获取学期、课程信息、提交选课）统一使用同一会话，确保登录态持续有效；
- 增加调试输出，便于定位登录问题。

**经测试，本版本于 2026-09-04 在 Python 3.10 环境下可正常登录并选课。**

## 使用说明  
- main.py为Python3编写的主程序，运行即可  
- class.txt为需要选择的课程列表，一行一个数据，因编码问题，第一行请留空或不要编辑。  
**选课顺序会严格按照class.txt中录入的先后顺序进行，在高优先级课程被选完/冲突前不会选低优先级课程，除非手动输入任意值字符回车跳过**  
- 按下回车之后会进入一个3s的循环，每秒选当前最优先的课程一次。（可以按多次开启多个计时循环）
